# Foodman - Restaurant Website

A responsive restaurant website built with **HTML**, **CSS**, and **JavaScript**.

## Features

- **Responsive Design** — Works on phones, tablets, and desktops
- **Mobile Menu** — Hamburger menu that slides open/closed on mobile
- **Product Cards** — Display restaurant dishes with prices and ratings
- **Testimonials Carousel** — Customer reviews with Swiper.js
- **Smooth Animations** — Scroll reveal effects with ScrollReveal.js
- **Modern UI** — Clean design with orange color scheme

## Technologies Used

- **HTML5** — Structure and semantic elements
- **CSS3** — Styling, flexbox, grid, media queries, animations
- **JavaScript** — Interactive features (menu toggle, animations)
- **Swiper.js** — Carousel for testimonials
- **ScrollReveal.js** — Scroll animation effects
- **Remix Icon** — Icon library for buttons and decorations
